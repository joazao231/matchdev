# Checklist para destacar o MatchDev no portfólio

## Repositório

- Fixar o MatchDev entre os primeiros projetos do GitHub.
- Usar o README principal como página de apresentação.
- Adicionar duas capturas: painel geral e resultado da análise de vaga.
- Manter dados de demonstração genéricos, sem informações pessoais ou currículos reais.
- Criar uma release `v1.0.0` com o arquivo compactado do projeto.

## LinkedIn

- Publicar o texto de `docs/linkedin-post.md` com um vídeo curto ou carrossel de imagens.
- Mostrar o problema nos primeiros segundos: “qual vaga realmente combina comigo?”.
- Demonstrar o fluxo: perfil → vaga colada → score → candidatura no funil.
- Marcar no perfil as competências Java, Spring Boot, Python, FastAPI, React, TypeScript, PostgreSQL e Docker.
- Adicionar o projeto à seção **Destaques** e à seção **Projetos**.

## Demonstração em entrevista

1. Abra o modo demonstração para garantir uma apresentação previsível.
2. Mostre rapidamente a arquitetura Java + Python + React.
3. Cole uma descrição de vaga de exemplo e explique os critérios do score.
4. Mova a oportunidade para a etapa de candidatura.
5. Encerre destacando segurança JWT, testes e decisões contra scraping.
